# Docker

Установите и запустите Docker Desktop с Linux-контейнерами. Приложение использует
существующую PostgreSQL на компьютере; новую базу или контейнер PostgreSQL оно не создаёт.
По умолчанию используются база `local`, схема `public` и пользователь `postgres`.

В PowerShell задайте пароль существующего пользователя PostgreSQL и собственный
секрет JWT длиной не менее 32 символов, затем запустите:

```powershell
$env:DB_PASSWORD = '<пароль PostgreSQL>'
$env:JWT_SECRET = '<случайный секрет длиной не менее 32 символов>'
docker compose up --build -d
```

Откройте http://localhost:8080. При необходимости задайте `DB_USER` и `DB_URL`
через переменные окружения перед запуском. В URL используется
`host.docker.internal` вместо `localhost`, поскольку приложение работает внутри
контейнера. PostgreSQL должна принимать подключения из Docker Desktop; при
необходимости настройте `listen_addresses`, `pg_hba.conf` и брандмауэр.

Для просмотра журналов используйте `docker compose logs -f app`, для остановки —
`docker compose down`. Эти команды не изменяют и не удаляют существующую базу.
Конфигурация предназначена для локальной разработки: приложение доступно только
на `127.0.0.1`, а переменные окружения контейнера доступны через Docker.
